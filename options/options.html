Miscellaneous Options

Configure Remapad's on-screen virtual keyboard and extension audio settings. Per-site layout overrides live in the Controller tab.

Virtual Keyboard

Master switch for the on-screen keyboard. When off, Remapad will not show the virtual keyboard on any page.

Trigger Mode

Controls when the virtual keyboard opens. Disabled mode still lets the gamepad cursor click elements normally.

Custom Trigger Selectors

CSS selectors, one per line. Matched elements are treated as keyboard triggers when focused or clicked, in addition to normal inputs and textareas.

Default Layout

Used as the fallback layout for sites without a per-site override.

When on, Remapad guesses the layout per page unless a site override is set.
