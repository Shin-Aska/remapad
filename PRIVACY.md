# Remapad Privacy Policy

Effective date: July 26, 2026

Remapad turns a gamepad into a browser controller. It operates locally in your
browser and does not collect, sell, share, or transmit personal data to the
developer or to third parties.

## Data Remapad handles

Remapad may handle the following information on your device so its features can
work:

- the hostname of the active website;
- gamepad connection state and button or stick input;
- controller mappings, navigation preferences, custom page selectors, and
  tutorial progress you configure;
- page elements on sites where you grant Remapad access, solely to perform the
  browser actions you mapped.

This information stays in the browser. Remapad has no analytics, advertising,
telemetry, account system, or developer-operated server.

## Local storage

Settings are stored with the browser extension storage API on your device.
Remapad does not use browser sync storage. You can remove stored data by
resetting Remapad's settings or uninstalling the extension.

## Website access

Remapad includes access to Netflix and Prime Video because they are its built-in
profiles. When you add another website, the browser asks you to grant Remapad
access to that site. Remapad uses this access only to read and interact with page
elements needed for controller navigation, mapped actions, the virtual cursor,
and the on-screen keyboard.

Remapad does not read or change pages for advertising, profiling, credit
scoring, or any purpose unrelated to its visible controller features.

## Network requests

Remapad does not send browsing history, settings, controller input, or page
content over the network. All executable code and runtime assets are packaged
with the extension.

## Data sharing and transfers

Remapad does not sell or transfer user data. Its use of information received
from browser APIs is limited to providing and improving the extension's
user-facing features, in accordance with the Chrome Web Store User Data Policy,
including the Limited Use requirements.

## Changes

Material changes to this policy will be recorded in this file and reflected by
the effective date above.
